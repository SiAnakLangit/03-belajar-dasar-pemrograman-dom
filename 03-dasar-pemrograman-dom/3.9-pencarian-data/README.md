# Data Demonstrasi Praktik 3.9

## Tujuan

Data ini digunakan sebagai data latihan untuk menguji program pencarian barang melalui terminal.

Program menggunakan dua field utama:

* `nama` — menyimpan nama barang.
* `kategori` — menyimpan kategori barang.

## Data yang Digunakan

| No. | Nama       | Kategori    |
| --- | ---------- | ----------- |
| 1   | Keyboard   | Perangkat   |
| 2   | Headset    | Audio       |
| 3   | Kamera     | Perangkat   |
| 4   | Kabel HDMI | Aksesori    |
| 5   | Flashdisk  | Penyimpanan |

## Tujuan Data Latihan

Kelima data tersebut digunakan untuk menguji beberapa kondisi pencarian:

1. Mencari data yang tersedia.
2. Mencari menggunakan sebagian nama barang.
3. Memasukkan input kosong.
4. Mencari barang yang tidak terdapat dalam data.
5. Menguji kondisi ketika tidak ada data yang dapat dicari.

Data ini hanya digunakan sebagai data demonstrasi untuk latihan pencarian dan tidak merepresentasikan data barang sebenarnya.
